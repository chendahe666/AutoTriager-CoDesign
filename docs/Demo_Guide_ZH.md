# 本地演示与人工验收

当前地址：<http://127.0.0.1:8502>。如果应用已关闭，在项目目录运行：

```bat
.venv\Scripts\python.exe -m streamlit run app.py --server.port 8502
```

1. 在侧栏选择 English 或中文，再选择 `bank-001`。
2. 阅读题目和调查窗口，点击“运行分析”。首次准备数据和调用模型可能需要几分钟。
3. 查看候选组件、可能原因和信息缺口。显示“完成”只代表流程完成，不代表因果解释已经确认。
4. 在证据区选择指标或组件观察，再查看来源文件、CSV 记录号和原始数值。
5. 选择接受为排查线索、拒绝解释或仍需核查，并写自己的理由。点击“记录判断”。
6. 切换语言，确认结果和判断仍然存在。已有模型说明保持生成时的语言，语言切换不会重新调用模型。
7. 如需保存，点击“导出本次调查”。关闭会话前导出，避免丢失人工反馈。

`bank-004` 是另一个真实案例。当前版本可以保留网络异常的可疑组件，但不强行区分网络延迟和丢包。这个“未确定”是有意保留的限制，不是把题目答对了。

如果出现 API 503、超时或请求额度不足，查看错误状态。不要把它当作成功结果。可稍后手动再次运行；程序不会切换付费模型。不要为了演示连续反复点击。

## 需要你反馈的内容

这是**人工验收**，当前不需要你补充密钥或重新选技术方案。

- 能否明白系统怀疑哪个组件，以及它依据什么？
- 能否找到一条原始记录，判断它是否支持解释？
- 哪个按钮、术语或结果让你困惑？

仓库里的截图反馈写明是自动测试，不能代替你自己的判断。最终课程提交由你决定。
